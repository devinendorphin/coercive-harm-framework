## Questions, fixed

**For each cell coded absent / n/d (misfit side):**
1. **Truly absent?** Is there any transcript passage showing the move's *function*, which the coder
   missed? (A miss would make this a *false misfit*.)
2. **Opportunity?** Did the room allow the move (shared life, access to the network, duration)? Cite
   the passage.
3. **Friction (amendment 6, C2 only):** when did the target first disagree, set a boundary or resist,
   and when did the first C2 act come? Cite both.

**For each cell coded ✔ (fits side):**
1. **Function shown?** Does the transcript show the move's function (C1: obligation/dependency/access;
   C2: rendering worthless; C3: cutting off support; C4: a false account given to the network; R-SEP:
   action against the target at exit or exposure)? Or only something resembling it?
2. If only the resemblance: **false fit**.
3. **C2 form** (amendment 6): *at friction* / *from the start*, with the passages.

## Rules

- **Verdict per cell:** *confirmed*, *false fit*, *false misfit*, *misfit stands*, or *insufficient
  transcript*.
- **A changed verdict must quote the transcript** (a short quotation with episode and approximate
  position). A gloss alone does not change a verdict.
- New amendments made after this file do not apply to this audit.
- Reader: Claude, the same model family as the original coder, not blind. This audit does not replace
  the blind second reader (Codex), which is still proposed.

## Refutation reading

The pattern claim is weakened if the fits side shows **false fits at a rate comparable to or above** the
misfit side's *false misfits*. It is strengthened if false fits are rare and the misfits mostly stand
or turn out to be scope cases.
